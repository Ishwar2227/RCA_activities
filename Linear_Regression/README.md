# Wine-Quality-Prediction-Using-Linear-Regression

A machine learning project that uses **Linear Regression** to predict wine quality scores based on physicochemical properties such as Fixed Acidity, Volatile Acidity, Citric Acid, Residual Sugar, Chlorides, Free Sulfur Dioxide, Total Sulfur Dioxide, Density, pH, Sulphates, and Alcohol.

The model is trained using the WineQT dataset and evaluated using Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and R² Score to measure prediction performance.
